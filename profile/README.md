## Envisioning

A research institute studying emerging technology and the futures it makes possible. The parts of that work that can be open, are: datasets, benchmarks, methods packaged for agents, an open spec for how people and agents share work, and the design system behind our apps.

### Starlings

[Starlings](https://starlingshq.com) is where our people and agents work on the same record. Every call, message, task and document is filed on the client or project it is about. The app itself is private. The subject model it runs on is published as an open spec.

| | |
|---|---|
| [starlings-subject-spec](https://github.com/envisioning/starlings-subject-spec) | The open standard behind Starlings: subject kinds, doors, records, a conformance suite, and agent skills you can install in Claude Code. Any tool may implement it. [starlingshq.com/spec](https://starlingshq.com/spec) |

### Research

| | |
|---|---|
| [research](https://github.com/envisioning/research) | Open dataset of emerging technologies: readiness, impact and investment scores, in Markdown and JSON. [envisioning.com/research](https://www.envisioning.com/research/) |
| [hindsight](https://github.com/envisioning/hindsight) | Published forecasts, checked against what happened. Each claim is dated, sourced and graded, with the evidence cited. Hindsight has no total score and does not rank forecasters. [envisioning.com/hindsight](https://www.envisioning.com/hindsight) |
| [national-capability-benchmark](https://github.com/envisioning/national-capability-benchmark) | What a country is capable of: anticipating, coordinating, learning, adapting, building. Nine dimensions, no headline ranking. [ncb.envisioning.com](https://ncb.envisioning.com) |
| [signals-benchmark](https://github.com/envisioning/signals-benchmark) | Open leaderboard for LLMs on signal-of-change generation. Multi-sector briefs, web-grounded judges, four-axis scoring. [signals.envisioning.com/benchmark](https://signals.envisioning.com/benchmark) |
